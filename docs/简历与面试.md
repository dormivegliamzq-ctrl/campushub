# 简历与面试材料

## 一、简历项目经历段落（任选 3~4 条，每条都是"问题→方案→数据"）

> CampusHub 校园论坛社区（独立开发）| Spring Boot 3 + MyBatis-Plus + MySQL + Redis + Vue 3

- 设计并实现校园社区后端，覆盖注册登录（JWT + BCrypt）、发帖、两级评论、点赞、关注、热门榜等完整业务闭环，配套开发 Vue3 + Element Plus 前端页面
- 实现点赞防重复的双保险方案：Redis Set 内存快速拦截 + 数据库唯一索引兜底，杜绝并发重复点赞导致的计数错误
- 设计帖子详情两级缓存，通过空值缓存解决缓存穿透、随机过期时间解决缓存雪崩，并在更新时主动删缓存保证一致性
- 基于 Redis zset 实现帖子热度排行榜（热度 = 点赞×3 + 评论×2 + 浏览×1），并设计榜单丢失后的惰性重建机制
- 通过 @RequireLogin 注解 + 拦截器实现接口级登录控制，ThreadLocal 传递用户上下文并在请求结束清理，防止线程池复用串号
- 点赞数/评论数更新与业务操作同事务，使用 IF 函数防计数为负；列表查询批量 IN 查作者，避免 N+1 查询

## 三、常见追问及回答要点

- **Q：项目并发量多大？** A：诚实回答"课程项目，未做压测；设计上针对高并发场景做了防重/缓存/原子更新等准备"。千万不要编数字。
- **Q：为什么自己写 JWT 不用 Spring Security？** A：本项目想完整理解认证链路（拦截器/注解/ThreadLocal 每个环节自己写）；面试可补充"了解 Spring Security 的过滤器链思想"。
- **Q：热榜 zset 和数据库数据不一致怎么办？** A：zset 是加速结构，每次互动动作都重算刷新；Redis 重启后惰性重建；极端不一致时以 DB 为准。
